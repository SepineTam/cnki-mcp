# 知网 Chrome 探索记录

观察日期：2026-09-18。使用实际 Chrome 页面进行少量检索，未下载全文。
不保留账户、Cookie、机构身份或临时签名链接。

## 实际走通的路径

1. 打开 [中国知网](https://www.cnki.net/)，观察搜索框以及“高级检索”
   “出版物检索”入口。点击“高级检索”打开新标签。
2. 进入 [高级检索](https://kns.cnki.net/kns8s/AdvSearch)。
   表单默认有主题、作者、文献来源三行，行间有 AND，行尾有匹配方式。
   页签包括高级检索、专业检索、作者发文检索、句子检索。
3. 切换专业检索，看到大文本框和可检索字段帮助。
   输入 `TI='因果推断经验研究中的中介效应与调节效应' and AU='江艇'`，
   点击“检索”，页面 URL 不变。向下滚动后看到 1 条结果。
4. 结果表提供篇名、作者、来源、发表时间、数据库、被引、下载和操作列。
   左侧出现 CSSCI、北大核心、AMI 等来源类别选项，顶部有排序控件。
   本轮确认了控件存在，没有逐一执行筛选或排序。
5. 点击篇名，检查新标签并进入详情。核对得到：

   | 字段 | 页面显示 |
   | --- | --- |
   | 题名 | 因果推断经验研究中的中介效应与调节效应 |
   | 作者 | 江艇 |
   | 单位 | 中国人民大学经济学院 |
   | 来源 | 中国工业经济 |
   | 正式年期页码 | 2022 (05): 100-120 |
   | DOI | 10.19581/j.cnki.ciejournal.2022.05.005 |
   | 在线公开时间 | 2022-06-11 10:55 |

   详情页明确区分在线公开时间和发表时间。后续可通过上述检索式或
   [DOI](https://doi.org/10.19581/j.cnki.ciejournal.2022.05.005) 回查。
   这里只验证题录、摘要和关键词的可读取性，不对论文研究结论作评价。
6. 点击“引用”图标，弹出引文窗口。截图中可见 GB/T 7714-2025 格式引文、
   知网研学、EndNote 以及“更多引用格式”。读取后关闭弹层。
   未继续打开“更多引用格式”或导出文件。
7. 点击详情的 `2022 (05)`，新标签打开“中国工业经济”期刊导航。
   左侧自动展开 2022 年，右侧显示 `2022年05期`，目录中出现目标论文。
   同页观察到“出版来源检索”与“本刊内检索”两种搜索入口、年份翻页与
   No.XX 期号。本轮没有另外切换年期或执行刊内搜索。
8. 在文章详情观察到 HTML阅读、原版阅读、CAJ下载、PDF下载入口。
   停在按钮前，未验证阅读器、下载权限、收费页或本地文件保存。

## 实际发现的操作经验

页面结构在高级检索和详情页都包含验证码组件的文字，但截图没有弹窗，
检索与打开详情均可正常完成。第一次仅根据结构文字判断有验证码是误判，
已经更正为先核对可见截图再请求人工处理。

点击会新开标签，原标签读取结果自然不变。不能因原标签无变化重复点击。
搜索结果最初出现时，链接地址可能先于题名文字加载，滚动到结果区域后
可读到完整表格。页面底部的推荐、服务和 AI 问题不能混进文章元数据。
